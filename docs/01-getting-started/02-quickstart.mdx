# Quickstart

## Install the CLI

```bash
curl -fsSL https://cdn.edgepython.com/cli/install.sh | sh
```

The installer works on macOS, Linux, and WSL. Open a new shell and check the install:

```bash
edge --version
```

To build from source instead, run `make wasm-cli js lucide` and then `cargo install --path cli` from the repo root. See the [CLI reference](/docs/reference/cli) for install details and flags.

## Run your first script

Create `hello.py`:

```edge-python
def greet(name):
  return f"Hello, {name}!"

for who in ["world", "edge", "python"]:
  print(greet(who))
```

```output
Hello, world!
Hello, edge!
Hello, python!
```

Run it from your terminal:

```bash
edge run hello.py
```

There is no build step. The CLI compiles the file and runs it.

## Import your first package

Edge Python ships no standard library, and nothing resolves until you declare it. Declare `json` first:

```bash
edge add json
edge lock
```

`edge add` writes the version into `edge.json` beside your script:

```json
{
  "imports": {
    "json": "0.1.0"
  }
}
```

`edge lock` then generates an `edge.lock` beside it, recording the URL and the digest that version resolves to.

Now create `app.py`:

```edge-manifest
{ "imports": { "json": "0.1.0" } }
```

```edge-python
import json

data = json.loads('{"name": "edge", "tags": ["fast", "small"]}')
data["tags"].append("sandboxed")
print(json.dumps(data))
```

```output
{"name": "edge", "tags": ["fast", "small", "sandboxed"]}
```

Run it:

```bash
edge run app.py
```

The manifest format lives in [edge.json](/docs/reference/modules#edgejson), and the generated file in [edge.lock](/docs/reference/modules#edgelock).
