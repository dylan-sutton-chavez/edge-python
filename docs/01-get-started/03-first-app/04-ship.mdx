# Ship the app

`edge build` packs the project and every package it declares into one artifact. `edge publish` sends that artifact to the registry, where anyone can add it with `edge add`.

## Name the package

The registry reads the name and the version from the manifest inside the artifact. Add them to `edge.json` with a one line description.

```json
{
  "name": "words",
  "version": "0.1.0",
  "description": "Count the words of a text and rank them.",
  "edge": "0.9.3",
  "imports": {
    "json": "0.1.0",
    "test": "0.1.1"
  }
}
```

A name is first come and permanent. Pick one nobody holds yet. [Package fields](/docs/reference/registry#package-fields) lists the rules for each field.

## Build it

> [!COPY] edge build

```text
$ edge build

  packed app.edge (6 files)
  114.27 KB

  run  edge run app.edge   or send it to an actor eval group
```

`app.edge` holds the code, the manifest, the lock and both packages. It runs on any machine with `edge` installed.

> [!COPY] edge run app.edge

Two other modes target other places.

- `edge build --app` writes `app`, a standalone binary that runs offline on the same OS and CPU with nothing installed.
- `edge build --web` writes `dist/`, a folder any browser runs, with the JS host and every package beside it.

[edge build](/docs/platforms/cli#edge-build) covers the three modes and their flags.

## Publish it

1. Create a token in [the settings](https://edgepython.com/settings#tokens).
2. Export it as `EDGE_TOKEN` in your shell.
3. Run `edge publish` on the artifact.

```text
$ export EDGE_TOKEN=edge_pat_...
$ edge publish app.edge
  published words 0.1.0

  add it with  edge add words
  https://cdn.edgepython.com/pkg/words/0.1.0/app.edge
```

The token signs the request and never leaves your machine. The registry reads the listing out of the artifact itself.

> [!WARNING]
> A published version is never overwritten. Raise `version` in `edge.json` and build again before each new release.
