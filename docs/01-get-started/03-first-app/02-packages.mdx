# Add a package

Edge Python ships no standard library. Nothing resolves until `edge.json` declares it. This page adds the `json` package to print the counts of `words` as JSON.

## Declare it

From the `words` folder, add the package.

> [!COPY] edge add json

```text
$ edge add json
  + json       0.1.0

  updated edge.json, run edge lock to resolve it
```

`edge add` looks the name up in the registry and writes its newest version into `edge.json`.

```json
{
  "edge": "0.9.3",
  "imports": {
    "json": "0.1.0"
  }
}
```

## Lock it

Resolve the declared version.

> [!COPY] edge lock

```text
$ edge lock
  + json       https://cdn.edgepython.com/pkg/json/0.1.0/app.edge

  wrote edge.lock
```

`edge lock` writes `edge.lock` beside the manifest. It records the URL and the digest of each declared version. `edge run`, `edge test` and `edge build` read the lock and never ask the registry themselves.

> [!IMPORTANT]
> Run `edge lock` again after every change to `edge.json`, and commit `edge.lock` with the code. A version the lock does not hold stops the run with `'json' is not locked, run edge lock`.

## Import it

A bare name such as `json` resolves through `edge.json`. Here is the package on its own.

```edge-manifest
{ "imports": { "json": "0.1.0" } }
```

```edge-python
import json

data = json.loads('{"name": "edge", "tags": ["fast", "small"]}')
data["tags"].append("sandboxed")
print(json.dumps(data))
```

```output
{"name": "edge", "tags": ["fast", "small", "sandboxed"]}
```

Now use it in `main.py`. The two functions stay the same. The script imports `json` at the top and prints the ranking as one JSON object.

```edge-manifest
{ "imports": { "json": "0.1.0" } }
```

```edge-python
import json

def count_words(text):
    counts = {}
    for word in text.lower().split():
        word = word.strip(".,!?\"'")
        if word:
            counts[word] = counts.get(word, 0) + 1
    return counts

def top_words(text, n=3):
    counts = count_words(text)
    ranked = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
    return ranked[:n]

if __name__ == "__main__":
    text = "The cat sat on the mat. The cat slept."
    print(json.dumps(dict(top_words(text))))
```

```output
{"the": 3, "cat": 2, "mat": 1}
```

Run it again.

> [!COPY] edge run main.py
